## System Architecture

```
creditcard.csv (ULB Dataset)
        ↓
ml/preprocessing.py    → data/processed/  (train/val/test parquets + scaler)
ml/features.py         → Behavioral Feature Engine (Digital Twin)
ml/train.py            → XGBoost + Isolation Forest + Optuna (Colab)
ml/evaluate.py         → Metrics, plots, evaluation_report.json
        ↓
models/                ← Download from Colab Drive output
        ↓
scripts/verify_model.py → SHA-256 checksums + smoke-validation
        ↓
backend/app/main.py    → FastAPI (startup gate refuses boot if verify fails)
        ↓
frontend/              → React + Vite dashboard
```

### Hybrid Model (Thesis Section 3.4–3.7)
- **XGBoost** (0.70 weight): Supervised, scale_pos_weight, SMOTE-ENN in CV folds, Optuna TPE tuning
- **Isolation Forest** (0.30 weight): Unsupervised anomaly detection, no labels used
- **Fusion**: `final_score = 0.70 * xgb_prob + 0.30 * if_normalized`
- **Tiered Decisions**: BLOCK (>0.85) | REVIEW (0.50–0.85) | APPROVE (<0.50)
- **SHAP**: TreeExplainer explanations for all score ≥ 0.50

### Digital Twin Engine (Thesis Section 2.3)
Per-user behavioral profile with Welford's online mean/variance, causal 1h/24h sliding windows, device entropy tracking. Same class (`ml.features.BehavioralFeatureEngine`) used at training and inference time — **no training/serving skew**.

### About the Dataset (Important)
The ULB European Credit Card Fraud Detection dataset is used:
- 284,807 transactions, 492 fraud (0.17%)
- V1–V28: PCA-anonymized (original features withheld for privacy)
- **No native user/device/geolocation fields** — synthetic user IDs are generated via deterministic hash-bucketing of Time + Amount. This is a known dataset limitation documented in the thesis.

## Quick Start

### Prerequisites
- Python 3.10+
- Node.js 18+ (for frontend)
- PostgreSQL 14+ (or Docker)

### Step A — Train the Model (Google Colab, once)

1. Upload `creditcard.csv` to Google Drive: `/MyDrive/fraud_project/data/creditcard.csv`
2. Open `notebooks/train_colab.ipynb` in Google Colab
3. Set `OPTUNA_TRIALS = 100` (or 50 for ~1-2 hr)
4. Runtime → **Run All** (3–6 hours on free Colab CPU)
5. Download `/MyDrive/fraud_project/models/` from Drive
6. Place contents into local `models/` directory

### Step B — Local Preprocessing

```powershell
# From project root
python -m venv .venv
.venv\Scripts\activate
pip install pandas numpy scikit-learn xgboost imbalanced-learn optuna shap joblib matplotlib seaborn pyarrow

python scripts/run_preprocessing.py
```

Expected output:
```
Train: 192,933 rows | Fraud: 0.1664%
Val:   34,047 rows  | Fraud: 0.1674%
Test:  56,746 rows  | Fraud: 0.1674%
```

### Step C — Verify Model Artifacts

```powershell
python scripts/verify_model.py
```

This verifies SHA-256 checksums AND runs smoke-validation (local metrics must match Colab within ±0.01). **Backend refuses to start if this fails.**

### Step D — 🚀 One-Click Start (Recommended)

Simply double-click:
```
start_all.bat
```
*(This automatically ensures PostgreSQL is running, launches the FastAPI backend on port 8000, starts the React dashboard on port 5173, and opens your browser.)*

6. **Admin Panel**: Move the BLOCK slider from 0.85 → 0.75 → simulate again → observe more BLOCKs
